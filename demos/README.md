# Standalone demos

The maintained application is `client/index.html`. Pages in this folder are independent experiments and older UI surfaces.

- `legacy/`: pages previously stored in the workspace root.
- `supergence-ui/`: older Supergence HTML, CSS, and JavaScript.
- Other HTML files: standalone simulations and visual experiments.

The backend serves this folder under `/demos/` and preserves existing aliases such as `/jarvis`, `/newfrontend.html`, and `/SupergenceUI.html`.

Do not implement app features only in these demos. Follow `AGENTS.md` and verify equivalent app behavior in Chrome.
