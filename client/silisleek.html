to a workspace.

Supergence brings conversations, files, and tools together so you can follow the work as it takes shape.

01

Start with an idea

Ask an agent to brainstorm, write code, or create files. Each chat has its own workspace on disk for its task.

02

See the work unfold

The workspace viewer shows files being written and commands running in the live terminal as the task progresses.

03

Choose how you work

Use the web cockpit or the optional desktop app. Connect a model provider through your configuration.

04

Stay in control

Proactive suggestions are disabled by default. When enabled, selected folder metadata and optionally the foreground window title can be sent to your configured model.

Supergence is local-first. Your configured model provider may receive prompts and selected data; commands run with your operating system permissions.
