SETUP WALKTHROUGH

Four Steps to Autonomous Superintelligence

From binary download to live autonomous task execution in less than two minutes.

01

Run Setup or Portable

Launch `Supergence Setup 1.0.0.exe` or `Supergence-Portable-1.0.0.exe`. The application initializes its local data folders automatically without overwriting existing settings.

02

Session Handshake

Supergence generates a cryptographic 64-character session secret (`SIS_SESSION_SECRET`). All WebSocket frames and HTTP requests require token matching, bound strictly to `127.0.0.1`.

03

Connect Model Provider

Bring your own API key for OpenAI, Anthropic, Gemini, or OpenRouter, or point Supergence to a local Ollama or vLLM server via the Preferences modal. Keys are encrypted in the local AES vault.

04

Autonomous Execution

Choose your Access Mode: `full-access`, `ask-before-executing`, or `approve-for-me`. Supergence operates your terminal, real Chrome browser, and workspace files autonomously to completion.

Windows Security & SmartScreen Transparency Note

In accordance with our AGENTS.md principles of honesty and transparency, please note that because SIS 1.0 is a brand new standalone release, Windows Defender SmartScreen may display a warning on initial launch ("Windows protected your PC").

Click "More info" and then "Run anyway". You can verify the integrity of your downloaded binary at any time by comparing its SHA-256 hash against the official values listed above using PowerShell: Get-FileHash "Supergence Setup 1.0.0.exe".
